# LEARN.md

## 1. Что сделали
Создали библиотеку для сравнения точности различных алгоритмов классификации текстов (Naive Bayes, LinearSVC) на одном наборе данных. Реализовали:
- Предобработку текста и разделение данных на обучающую и тестовую выборки.
- Логику сравнения метрик качества (precision, recall, F1) для нескольких классификаторов.
- Визуализацию результатов (опционально).
- Тесты для проверки корректности работы классификаторов.

## 2. Что разобрать (концепции)
- Математика и логика работы Naive Bayes и LinearSVC.
- Метрики качества классификации: precision, recall, F1-score.
- Предобработка текста: токенизация, стемминг, удаление стоп-слов.
- Разделение данных на обучающую и тестовую выборки.
- Визуализация результатов: confusion matrix, ROC curve.
